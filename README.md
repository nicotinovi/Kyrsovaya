# Full House Club

Веб-приложение для автоматизации управления турнирами спортивного покерного клуба.

Курсовая работа по дисциплине "Проектирование информационных систем".

## Стек технологий

Backend:

- Java 17 LTS
- Spring Boot 3.5
- Spring Web
- Spring Security
- JWT
- Spring Data JPA
- PostgreSQL
- Flyway
- Bean Validation
- OpenPDF

Frontend:

- React
- TypeScript
- Vite
- REST API
- CSS

## Роли пользователей

В MVP реализованы две роли:

- `VISITOR` — посетитель клуба;
- `ADMINISTRATOR` — администратор клуба.

## Основные возможности

Посетитель может:

- зарегистрироваться;
- войти в систему;
- просматривать расписание турниров и тренировок;
- записываться на мероприятие;
- отменять свою запись;
- просматривать личный кабинет;
- просматривать рейтинг игроков.

Администратор может:

- создавать мероприятия;
- редактировать мероприятия;
- отменять мероприятия;
- удалять мероприятия без активных записей;
- просматривать участников мероприятия;
- вручную добавлять посетителя на мероприятие;
- подтверждать присутствие участника;
- начислять очки за турнир;
- пересчитывать рейтинг;
- скачивать отчет по турниру в CSV и PDF.

## База данных

Используется PostgreSQL.

Основные таблицы:

- `users`
- `events`
- `enrollments`
- `player_ratings`
- `rating_entries`

Схема создается через Flyway-миграцию.

## Запуск backend

Перед запуском нужно создать базу данных PostgreSQL:

```sql
CREATE DATABASE pokerclub;

```

Настройки подключения находятся в файле:

```text
backend/src/main/resources/application.properties
```

Запуск backend выполняется из IDE или командой Maven:

```bash
cd backend
mvn spring-boot:run
```

Backend запускается на:

```text
http://localhost:8080
```

## Запуск frontend

```bash
cd frontend
npm install
npm run dev
```

Frontend запускается на:

```text
http://localhost:5173
```

## Тестовые пользователи

Администратор создается автоматически при запуске приложения:

```text
Email: admin@pokerclub.local
Password: admin12345
Role: ADMINISTRATOR
```

Посетителя можно зарегистрировать через интерфейс приложения.

## REST API

Основные группы endpoint:

- `/api/auth/**` — регистрация, вход, текущий пользователь;
- `/api/events/**` — расписание мероприятий;
- `/api/enrollments/**` — запись и отмена записи;
- `/api/admin/events/**` — управление мероприятиями;
- `/api/admin/enrollments/**` — управление участниками;
- `/api/ratings/**` — рейтинг игроков;
- `/api/admin/tournaments/{id}/reports.csv` — CSV-отчет;
- `/api/admin/tournaments/{id}/reports.pdf` — PDF-отчет.
